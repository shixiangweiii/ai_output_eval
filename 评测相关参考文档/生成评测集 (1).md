#### 1、“实验室”评测集生成

*   题目难度级别：简单、中等、困难
    
*   难度分布：40分 + 40分 + 20分
    
*   难度定义：
    
    *   简单：以原文事实召回为主，回答不涉及逻辑推理
        
    *   中等：在原文召回基础上，回答涉及1～2跳（限于单个文档内，跨多章节）的逻辑推理
        
    *   困难：在“中等”难度基础上，回答涉及至少3跳（跨章节 + 跨文档）的逻辑推理
        
        *   其他“骚操作”：回答要求反问、回答涉及再调用其他外部数据MCP等
            
*   评测集其他要求：
    
    *   update 4/26 by AI补充
        
    *   对抗性样本：生成包含误导性信息、模糊指代或带有攻击性的用户提问，测试拒识能力，不该回答时坚决不答
        
    *   多轮对话上下文：除了单轮问答，需生成依赖上文信息的追问，测试上下文记忆与关联能力（对于RAG接口，参考arag方式 openai 格式可传入对话历史）
        
*   原始文档影响难度因素：
    
    *   长文档，例如中篇小说长度
        
    *   专业文档，例如行业报表
        
*   对于回答格式要求：答案 + 推理路径 + 原文片段引用
    
    *   召回结果的引用来源的准确性
        
    *   幻觉检测
        
    *   推理路径有效性
        
    *   图片召回等多模态召回
        
*   评分标准：答案 + 过程 + token消耗成本
    
    *   答案要正确
        
    *   推理过程也要正确
        
    *   原文来源、原文引用要正确
        
*   GT类型
    
    *   返回内容：
        
        *   正向case
            
            *   是否正确召回目标内容，回答是否正确，思考推理过程是否正确
                
        *   对抗案例
            
            *   例如，指出目前文档的内容地区存在冲突和分歧，无法判断出标准答案
                
    *   返回工具调用：作为对抗案例，目前文档中无答案，拒答或者显式明确返回需要调用外部工具

* 跨章节信息依赖
* 先定义后引用
* 局部与全局信息冲突（需消歧）

### ✔ 检索复杂性

* 同一实体多种表达（别名 / 缩写 / 代号）
* 跨段落信息拼接才能回答
* 隐含引用关系（非显式说明）

### ✔ 推理复杂性（必须至少一种）

* 多跳推理链（A → B → C）
* 条件逻辑（如果/否则）
* 时间演化对比（历史 vs 当前 vs 未来）
